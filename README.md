# JavaScript Learning Projects

This repository contains a collection of small JavaScript projects built while learning core frontend development concepts such as DOM manipulation, event handling, and state management.

The focus of this repo is on understanding how JavaScript works in real applications without using frameworks or libraries.

---

## Projects Included

### To-Do App

A simple task management application built using vanilla JavaScript.

**Features:**
- Add new tasks
- Delete tasks
- Mark tasks as completed or incomplete
- Dynamic rendering of tasks in the DOM
- State-driven UI updates

**Concepts practiced:**
- DOM manipulation
- Event listeners
- Array methods (`push`, `filter`, `forEach`)
- Objects and state management
- UI re-rendering based on state changes

---

## How to Run

1. Clone the repository: https://github.com/Abugelis/JS_practice.git

2. Navigate to the project folder you want to run.

3. Open `index.html` in your browser.

No build tools or dependencies are required.
